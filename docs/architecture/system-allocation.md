# Preliminary System Allocation

**Document ID:** OR-ARC-003  
**Revision:** 0.1  
**Status:** Draft

## Logical Elements

### Wearable Unit

Responsible for user audio, local controls, status, battery monitoring, wireless participation, security, diagnostics, and recovery.

### Replaceable Battery

Provides stored energy and required electrical protection or identification.

### Charging Equipment

Provides controlled charging for one or more batteries or wearable units.

### Headset Assembly

Provides microphone capture, earpiece reproduction, cable, connector, and user fit.

### Local Service Utility

Supports authorized firmware update, diagnostics, configuration, and manufacturing/service workflows without cloud dependency.

### Production and Service Fixtures

Support programming, identity provisioning, electrical tests, RF tests, audio tests, and fault isolation.

## Allocation Principle

No element outside the wearable crew system may be required for active match communication after setup.
