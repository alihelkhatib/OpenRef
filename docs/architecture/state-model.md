# System State Model

**Status:** Draft v0.1

Candidate states include Powered Off, Boot, Self-Test, Ready Unconnected, Crew Formation, Connected Standby, Active Communication, Degraded Communication, Fault Recovery, Charging, Firmware Update, Recovery Mode, Service Mode, and Safe Shutdown.

Each finalized state shall define entry conditions, permitted actions, communication behavior, indications, exits, transitions, timeout behavior, and failure behavior.
