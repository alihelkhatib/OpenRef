# User Stories

## Communication

As a referee, I want to hear every official clearly so that I can make accurate decisions.

As an assistant referee, I want to interrupt immediately if I observe a critical incident.

As a fourth official, I want to communicate without unnecessarily disrupting the referee.

---

## Reliability

As a match official, I want the communication system to operate for the entire match without requiring intervention.

As a match official, I want the system to recover automatically from brief interference.

---

## Simplicity

As a referee, I want to begin using the system within one minute.

As a tournament official, I want to replace damaged equipment quickly.

---

## Comfort

As an official, I want to forget I am wearing the equipment.

As an official, I want to comfortably wear the equipment for multiple matches.

---

## Durability

As an official, I want the equipment to survive rain, sweat, mud, drops, and frequent travel.
