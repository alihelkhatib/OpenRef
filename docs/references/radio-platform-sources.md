- `FG23-DK2600A`: 868–915 MHz +14 dBm development kit.

## Source-Control Rule

Do not copy vendor example code into OpenRef without recording:

- exact SDK release;
- source file;
- applicable license;
- modifications;
- binary dependencies.

## Procurement Rule

Availability, pricing, board revision, lifecycle status, and exact frequency variant shall be rechecked immediately before purchase.
