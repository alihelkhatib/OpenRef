## Source-Control Rule

Do not copy vendor example code into OpenRef without recording:

- exact SDK release;
- source file;
- applicable license;
- modifications;
- binary dependencies.

Availability, pricing, board revision, and vendor lifecycle status shall be rechecked immediately before purchase.
