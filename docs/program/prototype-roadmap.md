# Prototype Roadmap

**Document ID:** OR-PGM-004  
**Revision:** 0.1

## Prototype 0 — Network Feasibility

Purpose:

- retire radio, topology, codec, latency, and power uncertainty.

Hardware:

- development boards;
- laboratory audio interfaces;
- external measurement equipment.

Exit:

- six-node proof;
- coordinator recovery;
- measured airtime;
- measured current;
- candidate band down-selection.

## Prototype 1 — Electrical Architecture

Purpose:

- validate custom electronics and subsystem integration.

Includes:

- processor;
- radio;
- audio front end;
- power regulation;
- battery interface;
- controls;
- debug and production-test access.

Exit:

- stable custom board;
- audio quality;
- power profile;
- update and recovery;
- basic EMC pre-scan readiness.

## Prototype 2 — Wearable Integration

Purpose:

- validate body-worn operation.

Includes:

- representative enclosure;
- antenna placement;
- battery latch;
- headset connector;
- sealing strategy;
- mounting system.

Exit:

- field range;
- motion stability;
- wet-hand controls;
- preliminary drop and rain performance;
- eight-hour endurance demonstration.

## Prototype 3 — Referee Field Trial

Purpose:

- collect officiating usability and reliability evidence.

Trial controls:

- noncritical matches or controlled scrimmages;
- backup commercial communication available;
- documented consent and issue logging;
- no unsupported release claims.

Exit:

- crew setup usability;
- speech intelligibility;
- comfort;
- fault frequency;
- prioritized corrective actions.

## Engineering Validation Build

Purpose:

- validate design intent against controlled requirements.

Includes:

- near-production materials;
- production-representative assembly;
- formal verification procedures;
- regulatory pre-compliance.

## Production Validation Build

Purpose:

- validate manufacturing, provisioning, acceptance testing, packaging, and service workflow.
