# Next Engineering Gates

**Document ID:** OR-PGM-003  
**Revision:** 0.1

## Gate A — Radio Class Down-selection

Required evidence:

- candidate frequency-band comparison;
- achievable channel capacity;
- latency;
- coexistence;
- antenna feasibility on a body-worn device;
- module and silicon availability;
- U.S. authorization path;
- power estimates.

## Gate B — Audio Architecture Down-selection

Required evidence:

- codec comparison;
- packetization interval;
- microphone front-end options;
- wind-noise approach;
- mixing architecture;
- acoustic output limits;
- processor load.

## Gate C — Power Architecture

Required evidence:

- representative load profile;
- cell and pack alternatives;
- replaceable-pack mechanics;
- protection architecture;
- charge logistics for six users;
- thermal analysis.

## Gate D — Proof-of-Concept Network

Exit criteria:

- six nodes;
- simultaneous synthetic or live voice streams;
- measured latency;
- coordinator loss and recovery;
- rejoin;
- nearby-crew isolation;
- measured power.

## Gate E — Wearable Engineering Prototype

Exit criteria:

- integrated battery, radio, audio, controls, and enclosure;
- representative headset;
- eight-hour endurance demonstration;
- field-range evidence;
- basic rain, sweat, drop, and running validation.
