# OpenRef Vision

OpenRef exists to make professional match-official communication practical for
more crews, clubs, and competitions.

The project should produce a communication system that is:

- reliable enough for match-critical coordination;
- simple enough for officials to set up under time pressure;
- affordable and serviceable enough for community sport;
- open enough that design decisions, test evidence, and limitations can be
  inspected;
- safe enough to respect hearing, battery, RF, privacy, and field-use risks.

The first technical milestone is Prototype 0: a six-node network feasibility
prototype that can generate evidence for radio, topology, codec, latency,
recovery, and power decisions before custom wearable hardware begins.
